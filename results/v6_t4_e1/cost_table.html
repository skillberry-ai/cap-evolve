Reading the table

  • Dollars: the merge-by-order and smart-merge bundles, which match Global on test in Table 1, cost $468 and $534 against Global's $949. That is 49% and 56% of Global.
  • Tokens: totals are close (332–369M for T-mrg, 339M for Global), but the mix is reversed. T spends 77–85% of its tokens in the optimizer; Global spends 54% in evaluation.
  • Compute time: Global used 3.6× the compute hours of T-mrg, almost all of it in evaluation (221 h). T-opt's optimizer time is higher (19.4 h against 8.9 h) because it ran 34 searches.
  • Global's evaluation breaks down as: validation gates $294, train incumbent sweeps $94, train screens $14, sealed test $138, and a post-run validation remeasurement of cand_0002 $53.

Definitions

  • Eval: the target agent running tasks. Optim.: the optimizer agent proposing edits, plus the smart merge's LLM merger. Merge by order and non-conflicting hunks are 10-second scripts with no LLM.
  • Compute time sums each trial's agent run and each optimizer call. Work ran in parallel on up to 15–30 cluster workers, so this is effort, not wall clock. Global's run took 66 h wall clock; each T-mrg evaluation took about 1–2 h.
  • Test evaluation is 5 trials per task for T-mrg and 10 for Global, so Global's $138 test line is about twice what a 5-trial test would cost.
  • The smart merge's $14 is an estimate at Claude Opus 5.5 list price from its measured tokens. Every other dollar figure is as billed by the gateway.
