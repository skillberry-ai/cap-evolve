Table C — per-category train/test split (skill-disjoint-safe)

For each category: a test subset of tasks whose skills all also appear in at least one train task of the same category — every skill the test set needs is still available, unseen-combination, in the train set. Intended use: optimize/tune skills on the train tasks, then evaluate held-out on the test tasks. Target was ~20–30% of each category, found greedily. Where a skill is unique to a single task within its category, that task can never be a test task — this caps the achievable split, sometimes to 0%.
