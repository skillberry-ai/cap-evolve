## How your output is judged
The saved output file is opened with `openpyxl.load_workbook(output_path, data_only=True)`, and the cells in answer_position are compared with a reference solution. Nothing is recalculated. So:
- **Write computed literal values, never formula strings.** A cell set to `"=SUM(A1:A5)"` through openpyxl has no cached value and reads back as empty. That scores as wrong even if the formula is correct. This holds even when the user's question says "I need a formula": work out what that formula would return in each cell, compute it in Python, and write the resulting value. The same applies to VBA/macro requests: do what the macro would do and write the resulting values.
- Existing formulas also lose their cached values when openpyxl re-saves the file. If an answer_position cell currently holds a formula, read its value with `data_only=True` and write a literal value into it (the unchanged value, or your new value).
- Comparison is per cell and type-sensitive. Numbers are compared as numbers (rounded to 2 decimals), and text as exact text. Write numbers as int/float (not "12" or "12 kg") unless the expected result is clearly text. Match the text conventions the sheet already uses: capitalization, spacing, and names exactly as written (e.g. a sheet name `Supplier_1` is not "Supplier 1").
