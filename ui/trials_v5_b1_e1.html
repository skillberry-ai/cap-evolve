Parsec v5 baseline — per-trial view (v5_b1_e1)

The original, unmodified parsec skill, zero-shot, 5 trials per task, no optimization, across all 136 v5 tasks. Every individual trial is drawn, so run-to-run stochasticity is visible rather than averaged away. Companion to heatmap_v5_b1_e1.html; narrative in results/v5/v5_b1_e1/summary.md.
Why this page exists. 68% of these tasks return a different reward across identical repeated trials. The implied noise floor is a per-task 95% CI half-width of ~0.13, so a single task's before/after difference below roughly 0.25 is indistinguishable from noise at 5 trials — while the suite mean is resolved to ~0.02. Any later optimizer arm should gate on suite-level movement, or raise trials for the gate. A page showing only means would hide exactly this.
