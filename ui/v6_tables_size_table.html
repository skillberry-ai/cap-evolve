Reading the table

  • One task's fix is small: a median champion adds about 1,200 words to a single task's bundle. Integrating all 34 still produces a bundle larger than Global's.
  • The smart merge kept almost everything: 45.5k of the 47.3k words the 34 champions added (96%). It reconciled conflicts but did not compress. Merge by order kept 57% of them, because a later task's hunk replaces any earlier hunk it overlaps.
  • Global deletes the most (818 words) and adds the least. It is the only arm that rewrites Seed text to a noticeable extent.
  • The untouched file is ocpv_agent.md in every arm. Size has a running cost: per-trial agent tokens on train were 37k for the Seed, 52–88k for T-mrg and 60k for Global.

Definitions

  • Words are whitespace-separated tokens in the eight skill files. Merge logs and optimizer notes are excluded.
  • Added and removed come from a word-level diff of each file against the Seed, summed over the eight files. A rewritten word counts once as removed and once as added.
  • Net = added − removed, so Seed + net = resulting words.
  • T-opt's 47,288 is the sum of 34 separate diffs, each counted once. It is not the size of any deployable bundle; it is what T-mrg had to integrate.
