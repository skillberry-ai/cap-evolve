Zero-shot skill transfer, 8 folds, generated 2026-09-02.

Read this before the table
  • Every fold reports best_id='seed', test_reward == test_baseline_reward, test_delta == 0.0. This is an artifact of --max-iterations 0: the transfer project's seed IS the frozen donor skill and is the only artifact evaluated, so cap-evolve compares it against itself. Real transfer effect = transfer_reward - native_seed.
  • For tasks with status KILLED_ceiling, native_optimized is the in-loop val score (results.json 'best'), not a held-out test score, because final_test is null - the run was stopped on saturation before a held-out eval ran.
  • 8 folds over 5 tasks in 2 domains; directional only.
