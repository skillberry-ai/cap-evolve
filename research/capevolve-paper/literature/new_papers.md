# New papers found by forward/backward/newest search (cutoff 2026-10-10; search run 2026-10-11)

Method: arXiv API title/abstract keyword searches sorted by submission date (queries on agent skill/harness/tool evolution, budgeted/adaptive evaluation, acceptance gates, merging, held-out selection, MCP tool descriptions), reference-list snowballing from the downloaded 64 PDFs and from the new papers, and arXiv-API title lookup of cited-but-unfound works. Venue/status text is copied from the per-paper card (source stated there). **ACL Anthology / OpenReview / PMLR were queried only for specific papers (see cards); no systematic venue-wide crawl was done. Semantic Scholar citation-count requests were rate-limited (HTTP 429): all citation counts "unavailable" unless a card names a source.** All 71 PDFs downloaded successfully (0 failed); hashes in `pdf_manifest_additions.json`. Search is not exhaustive: arXiv keyword search cannot see body-text citations; newest papers (Oct 2026) have no citation data.

Cards: `cards/new/<slug>.md` (FULL = full template, SHORT = 8-12 line triage). Papers are relevant to CapEvolve claims (a)-(f): (a) budget-aware/adaptive/posterior evaluation allocation; (b) verified merging of branches; (c) joint heterogeneous surfaces under one gate; (d) honest sealed held-out measurement with accounting of failed search; (e) memory of failed edits; (f) agent as controller of the search.
