# Novelty matrix and claim-safety analysis

Prepared by lit-lead on 2026-10-11 (search cutoff 2026-10-10). Data: `novelty_matrix.csv` (71 rows: 43 core papers/papers-groups from the 64-PDF package, 26 newly found papers, and the two CapEvolve algorithms). Source of every cell: the per-paper card (`cards/<slug>.md` for the core set, `cards/new/<slug>.md` for new finds), each of which cites PDF pages/tables. A cell reads "n" when the card states the paper does not do it, "?" when unverified, and "p(...)" for partial.

How to read the surface columns: P = natural-language prompt/instruction; T = executable agent-side tool code; M = MCP-visible or agent-side tool *descriptions* (no prior method was found that edits an MCP server's exposed descriptions/exposure as such; several edit agent-side tool descriptions/docstrings and are marked partial); S = multi-file skill package or skill document; H = harness/workflow/agent code.

Caveats that apply to every conclusion below:
1. The search is keyword search on arXiv (title/abstract) plus reference snowballing; it is **not exhaustive**. "Not found" means "not found in the 135 papers read", not "does not exist".
2. Most of the 2026 papers are single-run, un-peer-reviewed preprints; their numbers are cited as author claims. Venue status in the table is only what the card could verify.
3. Priority: the CapEvolve repository was created 2026-06-15 (GitHub API) and is Apache-2.0, but there is no paper yet; repository dates do not establish scientific priority against papers on arXiv. Many of the closest competitors (DarwinX, AutoSaddler, BONSAI, SkillCommit, HarnessLens, BudgetAPO, SAGE) were posted July-October 2026, i.e. after the repo was created, but a reviewer will compare the submitted paper against what is public at submission.
4. Only one paper found cites CapEvolve: SkillMorph (arXiv title "Trajectory-Guided Fault Localization for Agent Skill Evolution", 2610.11858) cites "CAP-Evolve" as a baseline and reports it second-best in its Table 1 (PDF p.11, `cards/new/tgfl.md`). Check which version of the repo they ran.

## 4. Claims that are unsafe as stated

1. "First" or "only" system to optimize prompts, tools, and skills jointly (SkillSmith, HarnessEvolve, HarnessCompass, AHE, Vestrum, DarwinX, AutoSaddler partial). Safe only with the explicit M (MCP) and S (multi-file skill package) qualifiers and without "first".
2. "First agent-driven / agentic optimization loop" (Meta-Harness, AHE, ReASearch, RLMOpt, OEO, CASD, HarnessOpt-Bench).
3. "Novel candidate archive/DAG" and "novel failure-driven reflective editing" (ADAS, DGM, GEPA, SkillSmith, AutoSaddler, DarwinX, BONSAI).
4. "Statistically principled / valid paired gate" for the k*SE rule (heuristic; PACE and SAGE are the principled versions; the code comment about sequential validity is not a proof for adaptive candidate generation).
5. "Novel budget-aware / adaptive / Bayesian-posterior evaluation allocation" in generic form (HGM first among them; CAPO, TRIPLE, ProTeGi, BudgetAPO, CRAFT, HGM, HarnessLens, VidHarness, VERSE, DarwinX, BONSAI).
6. "Novel verified merging" in generic form (DarwinX, AutoSaddler, BONSAI, SkillCommit, GEPA, MESH-Harness).
7. "Novel memory of failed edits" (SkillOpt, SkillSmith, AutoSaddler, DarwinX, ReASearch, Vestrum, BONSAI).
8. "Novel sealed/honest held-out protocol" (SkillOpt, OEO, RLMOpt, HarnessOpt-Bench) and "first to count the cost of failed searches" (ActiveSaddler, OEO, Skill Issue, Bad Genius, RobustSGPO, Vestrum).
9. Any SOTA / "outperforms GEPA/SkillOpt/EvoSkill" claim without matched budgets, same splits and independent seeds: published baselines in new papers are frequently copied from the GEPA paper (MEGA, Exploit More Explore Smarter, Naive Prompt Optimization) or reimplemented (VERSE), and gains are often within 1 SE (RLMOpt) or single-seed.
10. Quoting CoEvoSkills' 71.1% SkillsBench as a held-out number or attributing it to EvoSkill (it is in-sample on 85 tasks with the task's own verifier as oracle, `cards/coevoskills.md`; EvoSkill reports no SkillsBench numbers per `cards/evoskill.md`).
11. Comparing against reported numbers whose held-out protocol is in-sample: DGM, SICA, HGM, AHE (89 TB2 tasks), CoEvoSkills, SBCO, Meta-Harness TB2, DarwinX TB2.1, COBRA, EvoAlloc.
