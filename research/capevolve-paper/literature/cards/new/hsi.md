- Title: Hierarchical Self-Improvement: A Framework for Task-Specific Evolvable Agent Harnesses (HSI)
- Authors: Tailin Zhou (sole author; HKUST) [1 author]
- arXiv 2608.08466 v1; first/latest 2026-08-09; venue: "Preprint" (p1), no comment; code https://github.com/TailinZhou/hsi (stated p1; license not checked).
- Editable surface: a task-family harness H (prompts, tools orchestration, memory, state, cross-step logic) for a frozen DeepSeek-V4-Flash-Preview on BALROG games; PLUS the evolver's own strategy code (seed generation, commit selection, archive maintenance, final version export) via a meta-evolver scope, with an outer execution anchor frozen (p4) -> a bounded form of OPTIMIZER SELF-MODIFICATION.
- Search: single frozen LLM in three scopes (task harness / evolver / meta-evolver); five stages: seed selection, main evolution, commit selection, meta-evolution, terminal best-version selection (fixed, non-evolvable); greedy archive; dev-time LCB reward; thinking off at task execution and on during rewriting.
- Evaluation/held-out: Setup A = full-set in-distribution (dev ratio 1.0, no held-out; TextWorld, BabyAI, Crafter, MiniHack, NLE); Setup B = BabaIsAI sub-suites with 80/20 (or 75/25) dev/val-or-test split (Table 3 p~19); results table reports "Best Dev" and "Best Test" (meta-on vs meta-off) with 1 test repeat; whether "Best Test" is a val-selected version or max over test is UNVERIFIED (label ambiguity).
- Headline: abstract: +39.3 BabyAI, +33.0 Crafter, +25.0 TextWorld, +15.0 MiniHack (in-distribution raw % progress); BabaIsAI held-out 0.98 (BreakStop, meta-on), 1.00 (GoTo); Make 0.36 vs init 0.00 (Table 2 p10); NLE no improvement.
- Budget/cost: step budgets per scope (50 react() steps per iteration; submit-best 50-80 steps); no dollar/token totals seen.
- Limitations: self-declared feedback-fidelity and backbone-capability bounds; tiny test sets; single run.
