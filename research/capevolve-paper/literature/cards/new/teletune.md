# TeleTune (slug: teletune)
- Title: TeleTune: Evolving Agent Skills From Offline Telemetry; authors Justin Chih-Yao Chen, Elias Stengel-Eskin, Yan Chen et al. (9 total; UNC, Microsoft); arXiv 2610.05437v2 (v1 2026-10-04, v2 2026-10-06); first 2026-10-04; preprint, "Oct 2026" header; arXiv comment gives project page only.
- Code: project page https://microsoft-teletune.github.io/ (arXiv comment); no repo or license verified.
- Surface: one text skill library (workflows + skills) in the agent prompt, plus workflow-based demonstration retrieval at test time (p2-4).
- Method: offline reflect-edit-validate on fixed logs without goals/replay; goal inferred by LLM; predictor scored by teacher-forced next-action accuracy ("skill-guided progress" Q); optimizer proposes edits from the first error per trajectory plus "the list of edits rejected since the last accepted step"; candidate kept iff Q improves on a dev split of logs; two stages (workflows then skills), stop after 5 consecutive rejections or 25 steps (Sec 2.2 p4-5).
- Eval/held-out: train/dev log split for edits; live tests WorkArena L1/L2 and Online-Mind2Web, same test tasks, 3 seeds, WebJudge (o4-mini) grading; test not used for selection (p6). Agent GPT-5.4 (Table 1 p7); also Mistral-3.5 perturbation analyses.
- Headline: WorkArena avg 77.1 vs best baseline 70.4 (AWM+Random-k); Online-Mind2Web 80.6 vs 72.9 (Table 1 p7); mean +/- over 3 seeds. L1 library 56 skills, 6.4K tokens.
- Cost: optimization tokens reported per setting (Table 4 p9: L1 total 173.84M tokens, L2 23.59M, M2W 330.15M; optimizer <0.5%); claims 5-75x fewer tokens than live validation (16x on L1) via counterfactual estimate (p9); test-time prompt overhead reported (636.9K vs 343-386K input tokens/episode on L1).
- RELEVANCE: low-med. Offline proxy-gated acceptance and rejected-edit list are weak overlap with (e) and cost framing for (a); no merge, no candidate DAG, no agent controller, surface is one text library + retrieval.
