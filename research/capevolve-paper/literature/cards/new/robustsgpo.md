- Editable surface: agent specifications (instructions, input/output contracts, agent set and routing) of the AgentX brainstorming multi-agent workflow (industrial recommender); permission levels alpha1 (one agent), alpha2 (any existing agent), alpha3 (add/remove agents, routing). Predefined code (Typed Compiler) writes/removes agent files. Not tool code/MCP/skills.
- Search method: builds on SGPO (AgentX): semantic-gradient diagnosis -> refinement agent -> paired replay accept/rollback (Eq.1-3, p2). RobustSGPO adds: (i) choose scope s, operation o, targets T BEFORE generation (Eq.5), (ii) exact-target check + predefined structural patch constructor, (iii) MAP-Elites-inspired archive A[c] of best validation snapshot per (scope,operation) category, max ten category slots, seeded reservoir; alternates incumbent and archive parents (p3). Permission schedule periodic 1->2->3.
- Archive / selection / merge / memory: archive of complete snapshots by edit category; every descendant must beat the CURRENT incumbent for admission (Eq.3 with eps=0.05, paired replays, safety check; one best valid candidate per round, p4); failed patches enter "refinement experience" (p2, memory of failed edits, claim (e)); no merge of snapshots (retained snapshots are parents, not merged).
- Feedback signal: paired replay scores with rubrics/judge on identical tasks and execution seeds (3 paired replays); failures/invalid proposals consume budget.
- Task splits / held-out: 120 tasks = two families (local instruction failures; cross-agent handoff) of 60; per family 30/15/15 optimization/validation/test => 60/30/30 overall; grouping by source conversation and requirement before splitting; "validation scores guide selection and retention, while test feedback is excluded from search" (p4); test trajectories plotted per round but not used (checkpoints selected by budget, not test, p6). 5 paired seeds.
- Benchmarks and models: single internal AgentX brainstorming workflow (industrial recommendation); model not named in text read (UNVERIFIED); judged 0-5 quality score.
- Metrics: test quality 0-5; completion success (30 held-out tasks); effective category coverage; valid/attempted structural proposals; charged tokens.
- Budget/cost reporting: YES. 95 runs, 7,350 candidate attempts (Table 1 p4); three proposals per round; tokens include generation, failures, replay, judging, archive; test evaluation excluded from search cost; equal-token comparison at 20M tokens (Table 3 p6): per-round cost 0.80/0.83/0.78/0.82/0.95M; RobustSGPO 21 rounds vs SGPO 25. Invalid proposals and retries consume budget. Rescoring of archived snapshots after task shift charged.
- Reported limitations: one brainstorming workflow only; "do not rank RobustSGPO against the above systems on shared benchmarks" (p1); retention overhead; category retention has lower destination endpoint than random retention; caller instructions not auto-updated for new agents (p3).
- Key results: E1 p4 final test: periodic 1-2-3 4.34, 3-2-1 4.24, random 4.17, fixed a1/a2/a3 3.85/4.07/4.06. E2 Table 3 p6: round-30 SGPO 3.82 -> RobustSGPO 4.30; success 60.0% -> 80.0% (18/30 -> 24/30); at 20M tokens 3.77 -> 4.14 (+0.37); margin over Structured Search shrinks 0.10 -> 0.04 at equal tokens. E3 p5-6: final source loss 0.33/0.31/0.15/0.31; random archive best destination endpoint 4.18.

- Task selection/curriculum: permission-level schedule (1->2->3) acts as a scope curriculum; tasks not selected adaptively; E3 task-shift protocol.
