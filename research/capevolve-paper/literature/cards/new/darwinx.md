# darwinx (SHORT) -- arXiv 2608.07545v1
- Title: DarwinX: Evolving Agent Harnesses Through Natural Selection
- Authors: Yifan Zhang, Yutong Dai, Juntao Tan et al. (12 authors total; Salesforce AI Research / Agentforce)
- arXiv 2608.07545 v1 (cs.NE); first/latest 2026-07-31; venue: arXiv preprint (no comment/journal_ref); code URL: none (evolves Salesforce's proprietary "Monet" agent harness, footnote p2).
- Editable surface: two layers, skill (prompts, memory, distilled knowledge) and code (tools, control flow, agent loop); merged child = H0 + delta_code + delta_skill + delta_prompt + delta_tool (p6) -- heterogeneous but no MCP descriptions.
- Search: population/archive tree of harness snapshots with edit deltas, per-task scores, trial evidence, lessons; per-round parent sampled (1-beta exploit max cumulative lineage gain, beta broaden); branches assigned to capability clusters; additive proposals; failure-, teacher-, self-derived signals; shared failure-theme memory K_g (p5-8).
- Selection/allocation: per-task avg@k; preserve-and-extend contract: promote iff net gain g>0 and bounded regression R<=delta (paired per-task, p5); verifier agent adjudicates promote/revert; two-speed: screen at avg@3 on rotating subsets, promoted child gets a preservation probe re-sampling the lineage's solved set, steering nodes confirmed at avg@5 on full suite (p8); MERGE: complementary specialists merged from common ancestor, child KEPT ONLY IF S(child) covers union of parents' solved sets, then confirmed under same avg@k rules (p6) = verified merging.
- Held-out protocol: varies by benchmark. TB2.1 is IN-DOMAIN (search optimizes and is scored on the same 89-task suite, p9) so 75.5 -> 83.2 (GPT-5.5) and 84.7 (GPT-5.6 Sol) are not held-out; TerminalWorld: evolve on 94 train tasks, freeze, single-attempt pass@1 on 41 disjoint held-out (28/41 = 68.3% vs matched Opus base 25/41, McNemar p=0.45, p18); WebArena-Infinity: evolve on 300 synthetic intents, report on 1,260 unseen real tasks, 43.5 -> 93.0 audit-clean; TB2.1-evolved harness unchanged on SWE-bench Verified 84.2% (narrow band, p18).
- Headline: Table 2 p10 TB2.1 avg@5: Monet(DarwinX) GPT-5.6 Sol/medium 84.7+-1.2; GPT-5.5/high 83.2+-1.2; base Monet 75.5+-3.5; Terminus 2 78.0+-1.2. Preservation: of 88 paired tasks 36 improve, 43 unchanged, 9 regress (p10).
