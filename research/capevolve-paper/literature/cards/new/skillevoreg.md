- Editable surface: whatever the host evolver edits: single skill document (SkillOpt), multi-skill library patches (SkillEvolBench), CREATE/MODIFY library ops (ContinualSkillBench) (p6-7). Regularizer wraps the native updater.
- Search method: not a search algorithm; a regularization layer at the candidate-update boundary of an existing evolver: (1) training-time skill dropout (mask random skill "atoms" in the context used to generate the update, then reconcile the diff into the full incumbent; Eq.2-4 p4); (2) complexity-aware local regularization (if structural complexity signal triggers, restrict edits to candidate-touched atoms + related atoms; per-atom op in {NOOP, MERGE, REWRITE, DELETE}; Eq.5-8 p5); (3) causal counterexample validation (CCV): select an eligible source case the incumbent and candidate both solve, LLM generates a targeted "attack" variant from the candidate's diff, evaluate incumbent and candidate on it; CCV-confirmed regression if incumbent passes and candidate fails -> one scope-constrained repair, else unchanged (Eq.9-12 p6). Then the native acceptance rule runs unchanged. Archive/selection/merge across branches: none (single incumbent). MERGE here = merging near-duplicate atoms inside one skill, not branches; validity of merges is only checked via CCV on one attacked case.
- Feedback signal: native benchmark verifiers/evaluators; LLM-generated attacked cases; deterministic structural complexity C(S) (Eq.13 App A.2).
- Task splits / held-out protocol: SkillOpt arm: SpreadsheetBench 100/100/200 train/val/test, SearchQA 400/200/1400, LiveMath 100/80/217; 8 epochs, minibatch 8, edit budget 4; "delivery" checkpoint chosen on validation vs "final" epoch-8 checkpoint; test = mean of two frozen evaluations of the exact snapshot (App A.2 p13-14). Motivating pilot used seed 41, 3 evaluation replays that are not independent training runs (App A.1 p12). Other benchmarks follow native protocols (SkillEvolBench second pass; ContinualSkillBench learn tasks 1-50, evaluate 51-100, two evaluations).
- Benchmarks and models: SpreadsheetBench, SearchQA, LiveMathBench, SkillEvolBench, ContinualSkillBench; models only described as "the same proprietary instruction-following LLM under a fixed inference configuration" (p7) - model not named in the main text (UNVERIFIED in appendix).
