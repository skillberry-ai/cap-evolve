# SkillOpt-Lite / HarnessOpt (slug: skillopt-lite)
- Title: SkillOpt-Lite: Better and Faster Agent Self-evolution via One Line of Vibe; authors Yifei Shen, Bo Li, Xinjie Zhang (3; LMMs-Lab, NTU MMLab, Microsoft); arXiv 2607.03451v1 (cs.SE); first 2026-07-03; preprint ("July, 2026" header; no comment/journal_ref).
- Code: https://github.com/EvolvingLMMs-Lab/SkillOpt-Lite (abstract p1); GitHub license API = MIT (checked 2026-10-11); README mentions OpenAI / Azure OpenAI / "OpenAI-compatible endpoint" auth.
- Surface: skill markdown (SkillOpt-Lite); HarnessOpt extends to agent harness scaffolding code (tool primitives, prompt context, loop policy, codegen shape, state memory) with skills read-only or co-optimized (Sec 5, p11-13).
- Method: coding agent (GitHub Copilot / Claude-Code-style) explores raw trajectory files on disk, mines consensus failure patterns, edits the skill file directly; per batch one candidate; gated by independent validation set: accept if better than current baseline, overwrite best_skill.md if above historical best (p9). 10 batches vs SkillOpt up to 4 epochs. Single lineage hill-climb; no archive, no merge (SkillOpt's tree merging and rejected-edit buffers are removed). HarnessOpt: round-0 human-approved bootstrap proposal, then automated rounds with allowlist/denylist, compile + smoke test (N=5) before full validation, git-reset rollback, feature toggles, and a "statistical dead band" on the validation gain (improvements below it need non-trivial soft-metric progress) (p12). Harness and skill optimized sequentially, not under a single joint gate.
- Eval/held-out: SkillOpt splits; for LiveMath and OfficeQA split changed from 2:1:7 to 2:2:6 train/val/test to reduce validation variance (p9). Table 2 p10 reports per-model, per-benchmark scores (single run, no CIs; which split = test is implied but not labeled UNVERIFIED). Pilot (Fig 2 p7): Copilot one batch with no validation vs SkillOpt 4 epochs.
- Headline: Table 2 p10: GPT-5.5 LiveMath 73.6 vs SkillOpt 64.8; GPT-5.4-nano LiveMath 55.7 vs 30.3 (+25.4); Spreadsheet GPT-5.4 79.4 vs 61.5; some cells lower (GPT-5.4-nano SearchQA 66.9 vs 68.8; GPT-5.4 SearchQA 76.3 vs 77.5). Table 3 p12 SpreadsheetBench: GPT-5.4-nano Init 0.2989, SkillOpt 0.5160, SkillOpt-Lite 0.6619, HarnessOpt w/o skill 0.7651, HarnessOpt w skill 0.7758; GPT-5.5 0.7620 (SkillOpt), 0.7972, 0.8363, 0.8577.
- Cost: no token/dollar/rollout accounting found (text search for 'cost' returned nothing); HarnessOpt evaluated only on SpreadsheetBench because other datasets showed minimal change (p12) - selective reporting.
