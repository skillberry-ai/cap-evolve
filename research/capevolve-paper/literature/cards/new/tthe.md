# tthe (SHORT) -- arXiv 2607.08124v1
- Title: TTHE: Test-Time Harness Evolution
- Authors: Jun Nie, Yonggang Zhang, Jun Song et al. (8 authors; HKBU, USTC, HKUST, TCL; Bo Han, Xinmei Tian corresponding)
- arXiv 2607.08124 v1 (cs.SE); first/latest 2026-07-09; venue: arXiv preprint (comment "15 pages, 5 figures"); code https://github.com/junnie00/TTHE (MIT per GitHub API; README states an OpenAI-compatible LLM client with llm.base_url/api_key_env).
- Editable surface: whole executable harness program (grounding, verification, repair policies) of a frozen-LLM solver; solver, proposers and judge are roles of the same frozen LLM.
- Search: during evaluation, on each UNLABELED test batch maintain a population of candidate harnesses; G agentic proposers (conservative-repair, exploratory, adversarial branches) refine over R generation rounds reasoning on execution traces; a separate LLM judge commits one candidate from execution-derived proxy signals; committed program persists to later batches (p2, p31 ablation). No gold labels in the loop; gold used only post-selection for measurement.
- Evaluation/held-out: transductive: the batch whose unlabeled traces select the harness is then evaluated after adaptation; authors state this "does not establish forward generalization" and prequential scoring is left to future work (Limitations p~10). Single seed; no compute-matched best-of-N baseline (stated limitations).
- Headline: 50-question hard Text-to-SQL slice (conditioned on DeepSeek's failures): baseline 12.0% -> 50.0% at G=3,R=3 (Table 1, ablation p~9); claw-eval 30-task slice 48.9% -> 69.8% mean graded score; other domains competitive programming, SWE, data-science coding.
- Budget/cost: search-budget ablation (G x R grid), batch size B=10 best; no dollar cost; selection regret (candidates generated but not committed) analysed.
- RELEVANCE: LOW-MED. Cited by Turbo Harness as related. For us: (d) cautionary example where adaptation and measurement share a batch (transductive), supports our sealed-test framing; (a) population of G proposers with a judge selecting is a form of candidate triage without labels. Not a direct threat; label-free setting differs.
