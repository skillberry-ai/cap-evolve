# badgenius (SHORT) -- arXiv 2609.18366v3
- Title: Bad Genius: Counterfactual-Guided Harness Evolution Beyond Task-Specific Shortcuts (method CHASE)
- Authors: Guojun Zhu, Xunheng Huang, Peng Yin et al. (6 authors; UCAS, NUS, CASIA)
- arXiv 2609.18366 v3 (read); first 2026-09-16, latest 2026-09-24; venue: arXiv preprint (comment "32 pages, 6 figures; includes references and supplementary material"); code URL: none found in text.
- Editable surface: harness around a fixed model (prompts, memory, retrieval, tools, control code) via Meta-Harness-style Proposer.
- Search/selection: Proposer evolves harness for 3 outer rounds; after each update a Challenger searches for an executable benchmark-protocol transformation (counterfactual benchmark) causing large "gain destruction"; a validity firewall checks task semantics; a held-out confirmation set decides if the counterfactual enters a finite archive A_t; later harness selection must keep gain >= eps=0.05 under all archived counterfactuals (OfficeQA example p9: H1 gain +8.16% under B_rel -> -5.10% under B_b1, so H2 reset to H0).
- Held-out protocol: task holdout is judged insufficient for benchmark-wide shortcuts; certification on 76 held-out OfficeQA questions evaluated under every benchmark in final archive, 3 rollouts per question; OfficeQA Pro V2 (90 q) as extra release; Syn-Ledger (320 synthetic tasks, 208 certification) has constructable shortcut-free B0 (p8-9).
- Headline: Table 1 p9 OfficeQA: RawHarness R_rel 67.98%, Meta-Harness 63.60%, HarnessCompass 64.04%, HarnessEvolve 69.30%, CHASE 68.86%; worst-case over archive R_min 67.98 (CHASE) vs 63.60 (Meta-Harness). Pro V2: CHASE 30.37 vs Raw 27.04. NOTE: Meta-Harness and HarnessCompass end BELOW the unoptimized harness on the released-benchmark certification set.
- Budget/cost: reports ALL episodes incl. discarded candidates (Table C.8 p29): optimization tokens Meta-Harness 224.31M (983 episodes), HarnessCompass 283.02M, HarnessEvolve 574.16M (2,214 episodes), CHASE 688.96M (3,439 episodes, 2.43x HarnessCompass); certification tokens Table C.7. Closest explicit accounting of unsuccessful search in this group (d).
- Limitations: small budget (3 rounds, thresholds fixed under limited budget, p9); theory on finite archives; two benchmarks only.
