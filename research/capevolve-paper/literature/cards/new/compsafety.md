# compsafety (SHORT) -- arXiv 2609.33123v2
- Title: Compositional Safety Failures in Harness Evolution: Identification and Runtime Monitoring
- Authors: Zhixiang Zhang, Zesen Liu, Wai Ip Lai et al. (5 authors; HKUST)
- arXiv 2609.33123 v2 read; first 2026-09-27, latest 2026-09-29; venue: arXiv preprint (no comment); code: none found.
- Editable surface: studied, not optimized: harness components memory, prompts, skills, tools and their updates in a self-evolving harness.
- Method: identifies "compositional safety failures" = individually safe, utility-preserving component updates that become unsafe when jointly active; typed hypergraph (component states = nodes, safety-relevant higher-order interactions = hyperedges) updated locally on harness change; hypergraph-guided runtime monitoring checks only interactions activated by the current execution before the action takes effect (p2, p8).
- Evaluation: Qwen3-32B fixed backbone; AgentDojo (banking), Agent-SafetyBench, Agent Security Bench; Table 2 p5: pairwise compositional failures 22/157 eligible panels (14.01%) AgentDojo, 2/11 (18.18%) Agent-SafetyBench, 19/1243 (1.53%) ASB = 43 pairwise failures, plus 18 irreducible 3-way failures; Table 3 p8: monitoring cuts residual failure rate to <=1.27% (AgentDojo 2/157) while checking only 20.1-33.6% of candidate actions; SHE 3.82% and HarnessLens 5.10% residual on AgentDojo; naive exhaustive checking 0.64%.
- Budget/cost: reports interaction-checking cost reduction vs exhaustive composition enumeration; no optimizer search cost (not an optimizer).
- RELEVANCE: MED, SUPPORTIVE for (b)/(c). Provides evidence that merging or jointly activating independently-validated edits to heterogeneous components (prompt, skill, tool, memory) can break safety even if each edit passes its gate -> motivates "verified merging" with joint-composition checks; also shows validating each edit alone is not enough for a joint-surface optimizer. Does not propose a competing optimizer. Note: non-adversarial, one 32B model, small panels (11 eligible on Agent-SafetyBench).
