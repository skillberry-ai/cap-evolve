# vestrum (SHORT) -- arXiv 2609.33822v1
- Title: Vestrum: Improving Agent Harnesses by Adapting Their Verification, Structure and Memory
- Authors: Jayant Parashar, Eugene F. Douglass, William C. Bastian, Suchendra M. Bhandarkar (Univ. of Georgia, Emory) [4 authors]
- arXiv 2609.33822 v1; first/latest 2026-09-27; venue: "Preprint. Under review" (PDF p1; arXiv comment "30 pages, 2 figures, 20 tables. Under review"); code URL: none found in text.
- Editable surface: prompts, tools, memory operations, control flow ("mechanisms" across verification, retrieval, decomposition, knowledge synthesis; p3), applied to GAM memory harness and Claude Code.
- Search: epoch loop diagnose failures into failure classes + task kinds -> propose scoped mechanisms -> generalization-check screen -> evaluate composed BUNDLE on dev -> prune neutral/harmful mechanisms -> admit only if criteria met (e.g. TB: pass checks Claude Code fails in every draw, lose no check on another task kind, cost <1.5x baseline; p4, Table 8); persistent lessons file records successful AND unsuccessful proposals (p2). Optimizer: Claude Opus 5.
- Evaluation/held-out: dev traces; validation where used (UltraHorizon fresh validation seeds used once; LoCoMo/TB validate dev gains; AMA/PathBench paired dev comparisons); one harness frozen before test; "No test outcome returned to search" (p3, p5). Not bandit/posterior; bundles evaluated together with 1.5x allowance for prune/retest.
- Headline: UltraHorizon 47.6 -> 59.8 over GAM (mean+-sd 47.6+-0.7 vs 59.8+-4.7, App Table 15 p25), TB4-Hard checks passed 63.7% -> 70.3% on 8 held-out tasks (2 draws) at 1.03x cost (p6), PathBench 67.5 -> 77.8 (abstract p1).
- Budget/cost: reports estimated task-agent evaluations (about 1/4 of GEPA on LoCoMo and AMA-Bench, same on UltraHorizon, p6) and learning tokens (~30M vs GEPA 22.8M LoCoMo; 9.5M vs 15.7M AMA; ~74M vs 21.9M UltraHorizon, Table 16 p25); TB search cost $123.5 incl. test runs (p9). Honest accounting of search spend: partial overlap with (d).
- Limitations (p9): one selected harness per setting, no independent search repetitions; small TB test (8 tasks); ablations one search per variant; GEPA differing surface/model.
- RELEVANCE: HIGH.
