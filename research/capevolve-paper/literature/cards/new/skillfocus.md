# SkillFocus (slug: skillfocus)
- Title: SkillFocus: Evolving Agent Skills via Capability Decomposition; authors Ning Wang, Zhiren Gong, Bingdong Li, Peng Yang, Aimin Zhou (5; ECNU, NTU, SUSTech); arXiv 2609.34397v1; first 2026-09-28; preprint (no comment/journal_ref).
- Code URL: none stated in text (unverified).
- Surface: single shared Markdown skill per benchmark.
- Method: LLM induces a fixed task-capability matrix Q from task specs before execution (3 explorer perspectives + consensus); each round scores capabilities by unresolved task mass pi_d*(1-q_d) on train outcomes, picks the max, builds an evidence bundle from training tasks needing that capability including prior revision attempts/outcomes H_t tagged to it, proposes ONE candidate; abstains if evidence insufficient (Sec 3.3 p4, Eq.4-5). Single lineage, <=5 rounds, 1 candidate/round (App B.3 p18).
- Evaluation/gate: candidate accepted only after "paired selection and training check" on whole skill (fixed selection set D_sel built once by greedy coverage/diversity/opportunity, with a reserve of S0-solved tasks to expose regressions; Sec 3.4 p4); test split closed until final eval. Seed 42, single run, no CIs (B.3).
- Headline: test acc avg 70.7 vs SkillOpt 63.3, GEPA 61.2, Trace2Skill 55.1 on SearchQA/SpreadsheetBench/LiveMath/IFBench (Table 1 p6); SSB 77.1 vs 62.1; DeepSeek-V4-Flash target, GPT-5.4 optimizer. Random selection set instead of constructed lowers accuracy 3.9-17.2 pts (p6, App A.6).
- Cost: cumulative evolution tokens counted incl. induction, initial executions, rejected and abstained candidates, excl. final test; 24% fewer tokens than SkillOpt on average (largest 54.3% SearchQA) (Sec 4.1-4.2 p6; B.4 p18). Baseline SkillOpt cost reconstructed from run history; baselines use native budgets/splits (B.2).
- Limitations stated (p9): requires identifiable recurring requirements, one optimizer-target pair, bounded evolution, whole-skill validation (edits not confined to target capability).
- RELEVANCE: med. Threatens (a)/(e) partly: capability-targeted task/evidence selection (curriculum over tasks by unresolved mass) and per-capability memory of prior attempts; selection-set construction is a task-allocation idea. Does not do candidate-level adaptive evaluation or merging.
