# emho (SHORT) -- arXiv 2610.08432v1
- Title: EMHO: EMbodied Agent Harness Optimization via Experience Traces
- Authors: Hyun Jung Lee, Jungtaek Kim, Jongwon Jeong et al. (6 authors; Korea Univ., Univ. of Arkansas, UW-Madison)
- arXiv 2610.08432 v1; first/latest 2026-10-06; venue: arXiv preprint (no comment); code: abstract says "can be found here" (link not extracted; UNVERIFIED).
- Editable surface: full embodied-agent harness (planning, context/memory construction, vision tool use [Depth Anything 3, SAM 3, zoom], grounding, failure recovery) with frozen Qwen3.5-9B / Qwen3.8-27B.
- Search: hill-climb with history: optimizer LLM reads all experience traces (accepted AND rejected candidates) and full harness history, proposes a targeted modification of the current parent; candidate replaces parent only if search-set success is strictly higher (Eq.3 p4, 10 iterations per task). EMHO-Merge: for a single shared harness over pooled subtasks, compares candidate vs parent per episode (gains = fail->success, losses = success->fail) and uses paired trajectories to guide refinement of when/how the revised behavior applies -- "merge" here means merging subtask objectives into one harness, NOT merging candidate branches.
- Evaluation/held-out: benchmark split evenly into disjoint search and held-out sets per task (EmbodiedBench navigation/manipulation); harnesses at every iteration evaluated on held-out; Table 1 p5: "EMHO entries report the best score attained on each split over the optimization iterations" => held-out figures are best-over-iterations on the held-out split itself (selection on held-out; optimistic) -- authors' own Limitations (p9) note that best-search harness is not always best on held-out and overfitting appears.
- Headline: gains up to +23.3 pp navigation, +33.3 pp manipulation on search set; Table 2 p6 full-harness vs skill-only: manipulation Base +33.3 vs +16.7, navigation Base +16.7 vs +10.0. No confidence intervals seen (single run UNVERIFIED).
- Budget/cost: 10 iterations per task; no dollar/token cost.
- RELEVANCE: LOW-MED. Evidence for (e) (rejected candidates' traces fed to next proposal) and per-episode paired gain/loss analysis (similar to our paired gate and per-task evidence) but in a simple strict-improvement hill-climb; name "Merge" is a distractor for claim (b). Cautionary example for (d): headline held-out numbers are max over iterations.
