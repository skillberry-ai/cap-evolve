# gate: #351 (single-task gain has delta == SE) is closed but still decided by float rounding; SKILL.md still calls it open

_Draft for `skillberry-ai/cap-evolve`. Base SHA `e3cb513`. Defect id D14 (campaign audit, parent #743/#744)._

## Problem
`ok = mean_d > k_se*se` compares equal quantities for a one-task improvement.

## Code locations
- `core/cap_evolve/gate.py:451-452`; `skills/algorithms/hill-climb/SKILL.md` ('Known gate edge case')

## Reproduction
`decide(0.5,0.5,mode='paired',paired_deltas=[1.0]+[0.0]*(n-1),k_se=1.0).accept` for n in (4,8,20,30,40,60) -> False False True False True False.

## Impact
Acceptance of single-task gains is arbitrary at small val sizes.

## Proposed correction
Reopen #351 or define a tie rule (`>` with a documented relative tolerance, or `>=`) and test it for all n.

## Acceptance test
- Test over n=2..200 asserts the same decision for a one-task gain at every n.
