# agent-optimize commit.py: `--decision accept` performs no gate check

_Draft for `skillberry-ai/cap-evolve`. Base SHA `e3cb513`. Defect id D09 (campaign audit, parent #743/#744)._

## Problem
`commit.py` has extensive attribution checks for rejects but `if accepted: run_dir.set_best(...)` executes on any `--decision accept` as long as `--val` (if given) equals the measured mean. `act.py promote` is the only path that couples accept to a gate verdict.

## Code locations
- `skills/algorithms/agent-optimize/scripts/commit.py:638, 868`
- `skills/algorithms/agent-optimize/scripts/act.py:433-438`

## Reproduction
Static read; or `commit.py --run-dir R --candidate-id X --from-dir work/X --decision accept` on a candidate with no gate row.

## Impact
In agent mode the champion is whatever the driving agent books; the paper must count only `promote`-booked accepts (event field `gate_mode`).

## Proposed correction
Require a passing `gate_check` row (or `judge` record) for `accept`, with `--accept-without-gate REASON` as recorded escape.

## Acceptance test
- `commit.py --decision accept` without a gate row exits 2.
