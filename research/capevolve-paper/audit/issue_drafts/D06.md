# reward_gated: hard-coded NOISE_FLOOR=0.031 imposes a ~0.085 minimum accepted effect; 'looks' is not enforced

_Draft for `skillberry-ai/cap-evolve`. Base SHA `e3cb513`. Defect id D06 (campaign audit, parent #743/#744)._

## Problem
`paired_reward` floors the SE at `NOISE_FLOOR=0.031`, measured on one run (`run_20261008_150326`), for every benchmark and split size. With `z_accept=2.734` (Bonferroni over 8 looks x 2 branches) an accept needs `dR > ~0.085` regardless of n_tasks/trials. The docstring claims the cumulative false-accept rate over up to 8 re-evaluations is <= 0.05, but no counter limits looks per candidate and nothing corrects across candidates.

## Code locations
- `core/cap_evolve/objectives.py:41` (constant), `84`, `92-95`, `166-176`, `302-380`
- `skills/algorithms/agent-optimize/scripts/act.py:388-408`

## Reproduction
`python3.12 -I audit/repro/r5_rg.py` and `r5b_rg.py` (no true effect = 0.0-0.5% accept; +0.05 true = 0.5-10%; +0.10 true = 10-39%; T=140 power at +0.05 *falls* with more trials as the floor binds).

## Impact
agent-optimize cannot promote moderate real improvements; failed promotions or failed confirmations may reflect the floor, not the optimizer. Any claim about agent-optimize effect sizes must state the MDE.

## Proposed correction
Default `noise_floor` to 0 (or to a per-run estimate from byte-identical repeat cells, which `digest.noise` already computes); add a per-candidate look counter and refuse after `looks`; document the family-wise rate across candidates.

## Acceptance test
- Test: with T=140 and 8 trials, a true +0.05 effect has power that increases with trials.
- Test: the 9th `promote` of the same candidate returns `refused: looks exhausted`.
