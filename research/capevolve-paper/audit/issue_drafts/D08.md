# agent-optimize applies no integrity seal, yet SKILL.md says core enforces the tamper guard; seal scope excludes the adapter/scorer in all algorithms

_Draft for `skillberry-ai/cap-evolve`. Base SHA `e3cb513`. Defect id D08 (campaign audit, parent #743/#744)._

## Problem
`integrity.snapshot` hashes only the candidate workdir copy; the project's `adapter.py`/`scorer.py`/tasks live outside it. The seal is OFF unless `protected_paths` is in the spec (the shipped template has it commented out). agent-optimize's scripts do not import `integrity` or reference `protected_paths`, but `SKILL.md` ('Invariants') says 'Core enforces the split seal, val-only gating and the tamper guard'. The optimizer is an unsandboxed subprocess with the full environment and Bash. (General isolation gap is #276/#365; this issue is the agent-optimize-specific false claim and the seal-scope bug.)

## Code locations
- `core/cap_evolve/harness.py:947` (`env = dict(os.environ)`), `2885-2925`
- `core/cap_evolve/integrity.py:60-73`
- `skills/algorithms/agent-optimize/SKILL.md` ('Invariants'); `grep -n "protected\|integrity" skills/algorithms/agent-optimize/scripts/*.py` returns nothing
- `plugins/cap-evolve/hooks/hooks.json` (matcher `Edit|Write|MultiEdit|NotebookEdit`)

## Reproduction
`FAKE_API_KEY=x python3.12 -I audit/repro/r6_isolation.py` -> `verify ok: True | scorer.py now: def score(): return 1.0`, manifest empty.

## Impact
No run in the paper can exclude scorer tampering mechanically; for agent-optimize the documented guard does not exist. Claims of tamper-proof evaluation must be removed or backed by a sandbox.

## Proposed correction
Seal the project eval surface (adapter, scorer, tasks) by hash at run start and verify before every gate and at finalize, for every algorithm incl. agent-optimize; correct SKILL.md until implemented; scrub provider keys from the optimizer environment where the CLI allows.

## Acceptance test
- agent-optimize `promote` returns indecisive/tamper when `project/scorer.py` changed since run start.
- SKILL.md claim matches behaviour.
