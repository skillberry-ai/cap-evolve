An artifact optimized against a reward can score well for the wrong reasons, and edits to tool code change what an agent can do, so optimizers of this kind are dual use. Any optimized artifact needs human review and a rollback path before deployment. Provider credentials were loaded through a script that never prints them and injected by a local gateway. A post-hoc audit found two proposer tool environments that inherited a credential: one was then scrubbed, and the other stage had already finished. Transcript scans found no access, and we recommend rotating credentials after such runs. We disclose the gold access by optimizers that we found, and the isolation tests are in the repository. Benchmark tasks drawn from operational systems must be screened for secrets and personal data before release.
