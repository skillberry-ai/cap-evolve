\section{Ethical Considerations}
\label{sec:ethics}

Optimizing against a reward can produce artifacts that score well for the wrong reasons, and edits to tool code change what an agent can do. Any optimized artifact considered for deployment needs human review and a rollback path. We disclose the optimizer gold access we found, and the isolation tests are in the repository. Tasks drawn from operational systems must be screened for secrets and personal data before release.
