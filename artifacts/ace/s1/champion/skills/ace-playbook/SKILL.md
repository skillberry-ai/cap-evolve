# ace-playbook

## Scripts

- [code-00091] `skills.ace_playbook.load_xlsx_safe`: call when openpyxl.load_workbook raises an error (e.g., 'Value must be either numerical or a string containing a wildcard' from malformed dataValidation/conditionalFormatting XML). Returns a normally-loadable openpyxl workbook from a sanitized copy, and also provides sheet_xml_path(path, sheet_name) which resolves a sheet name to its worksheet XML part via xl/_rels/workbook.xml.rels.
- [code-00152] `skills.ace_playbook.normalize_date`: call on any value read from a date column before year/range filtering — it converts datetime objects (passthrough), Excel date serial numbers (int/float, e.g. 44392), and common date strings to datetime.datetime, returning None only for genuinely blank cells. Use it instead of isinstance(x, datetime) checks, which silently drop all serial-stored dates.
- [code-00092] `skills.ace_playbook.read_sheet_xml`: call when openpyxl/pandas both fail to load a worksheet (e.g., malformed dataValidation XML) and you must read the sheet's raw values from the xlsx zip. Returns a list of row-lists of cell text values.
- [code-00008] `skills.ace_playbook.verify_output`: call after saving to re-open the output workbook and print the target range's values and types for verification. Returns the list of (cell, value, type) tuples.
- [code-00014] `skills.ace_playbook.verify_values`: call after saving to check the answer range holds actual computed values (not just formula strings) and to diff the output against the original workbook's computed values, reporting cells that are empty, changed, or lost outside the intended edit range.

## Notes

- [calc-00153] Before filtering on any date column, call skills.ace_playbook.normalize_date.normalize_date(v) (or year_of(v)) on each cell value — never gate rows with isinstance(v, datetime): openpyxl returns unformatted date cells as raw integer Excel serials (e.g., 44392 = 2021-06-05), so a datetime-only filter matches zero rows and silently produces a total of 0. After normalizing, print how many rows parsed to a date and how many fell in the target year — a parse count of 0 or a year-match count of 0 is a representation bug, not an empty dataset.
- [misc-00009] Use skills.ace_playbook.verify_output.verify_output(output_path, sheet_name, cell_range) after every save to confirm the written values match expectations (correct values, correct string/number types, correct formatting). This replaces re-running solution code as a verification step.
- [misc-00015] After every save, use skills.ace_playbook.verify_values.verify_values(output_path, sheet_name, cell_range, original_path=input_path) to confirm the answer range holds actual computed values (data_only=True view) and that no cells outside the target range lost values or changed. This catches the two most common silent failures: formula strings with no cached values, and re-saving dropping cached values of untouched formula cells. Do not trust checks that only print formula strings.
- [misc-00027] Import helper functions precisely on the first attempt: `from skills.ace_playbook.verify_output import verify_output` and `from skills.ace_playbook.verify_values import verify_values` — do NOT `import skills.ace_playbook` and call the module itself (it is not callable). If a helper import or call fails (TypeError/ImportError), fall back to plain openpyxl re-open-and-print verification instead of retrying the helper.
- [misc-00082] Before calling a playbook helper for the first time, check its actual signature rather than guessing parameter names: run `import inspect; print(inspect.signature(skills.ace_playbook.verify_output.verify_output))`. Note verify_output takes `path` (not 'output_path'), plus optional sheet_name and cell_range; verify_values takes output_path, sheet_name, cell_range, and optional original_path/original_sheet. If a helper call still raises TypeError/ImportError, fall back immediately to plain openpyxl re-open-and-print verification instead of retrying.
- [misc-00093] When openpyxl raises 'Value must be either numerical or a string containing a wildcard' (malformed dataValidation XML) or a sheet otherwise fails to load: for WRITING, call skills.ace_playbook.load_xlsx_safe.load_xlsx_safe(path) to get a loadable workbook from a sanitized copy; for READING values only, call skills.ace_playbook.read_sheet_xml.read_sheet_xml(path, sheet_name) to read the sheet's raw values directly from the xlsx zip. Both resolve sheet-name-to-file mapping via xl/_rels/workbook.xml.rels (the sheetId attribute lives in xl/workbook.xml, never inside the worksheet part — do not search worksheet XML for it).
