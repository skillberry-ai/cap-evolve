# Wiki index

- [ground-truth-reference-sheet](wiki/patterns/ground-truth-reference-sheet.md): Task workbook contains a reference sheet (e.g. 'Manual Result', 'Desired Sheet1 after ...') with the expected output; agents that re-derive values from raw data get ordering/content wrong. FIX: check for reference sheets first and copy their values verbatim into answer_position (165-23 iter7 passed using its 'Desired' sheets to confirm row-deletion semantics).
- [expected-value-hints-in-instruction](wiki/patterns/expected-value-hints-in-instruction.md): Instructions or the input file state concrete expected values/examples (pre-filled example results in the answer range, 'a payment made in April ... March column', '3% incentive') but agents submit without asserting them. FIX: locate and assert every stated example before finishing; the user's own complaint paragraph is a specification (iter5: 6239 18/18, 46121 2/48, 11842 2/96; iter6: 56786 191/197; iter7: 46121, 56786, 6239 again; iter8: 56786 191/197 4th time, 46121 2/48 3rd time).
- [self-consistent-verification-trap](wiki/patterns/self-consistent-verification-trap.md): Verification only re-prints the agent's own values or formula strings, so wrong conventions pass self-check but fail the grader (56786 iter5/6/7/8: 191/197 wrong, pre-filled example cells never read; 6239 iter7 verified only its own grid). FIX: evaluate against source data in Python and assert against example cells found in the INPUT; never finish on a small mismatch count.
- [formula-never-evaluated](wiki/patterns/formula-never-evaluated.md): Answer is a formula; agent writes a plausible string, verifies only the formula TEXT, and the boundary convention is wrong ('number LOWER than expected', 46121 iter5/7/8). FIX: re-implement the formula in Python, compute the number, assert it matches the worked-example value in the input, testing both boundary variants.
- [formula-padding-instead-of-values](wiki/patterns/formula-padding-instead-of-values.md): Grader expects static VALUES but the agent writes IFERROR(INDEX/SMALL/IF...))"" formula strings padded across the whole answer range (1818 iter7 AND iter8 t2: 28 cells 'written past where the answer ends'; iter8 first had correct values then REPLACED them with padded formulas). FIX: compute results in Python and write values only for real result rows; if an earlier round wrote correct values, do not rewrite them as formulas.
- [inspect-then-write-then-verify-loop](wiki/patterns/inspect-then-write-then-verify-loop.md): Success pattern — passing traces inspected real cell values with openpyxl, wrote only real results, and printed a read-back of the saved file; failing traces guessed structure or never printed a read-back. FIX: always follow the 3-phase loop and print the verification output in the trace (iter7: 105-24, 165-23, 1818__t1 passed; iter8: 30930__t1, 10452, 408-39 passed this way).
- [skill-import-unavailable](wiki/patterns/skill-import-unavailable.md): `from skills.spreadsheet_helpers import helpers` raises ModuleNotFoundError in the executor even when active, wasting a round (iter5-7; iter8: 30930__t1 wasted round 1 then passed). FIX: always start round 1 with the guarded try/except paste-in preamble; never run an unguarded skill import.
- [typed-value-not-formatted-string](wiki/patterns/typed-value-not-formatted-string.md): Agents write number formatting as strings or ints where the grader wants float/int exactly ('2 cell(s) hold int where float expected', 6239 iter5). FIX: write real typed values (float when non-integral expected), use round()/cell.number_format for 'decimal places' — note iter6 46646 also required per-value number_format (0 / 1 / 9 dp rules), not round() on the value.
- [guessed-domain-semantics](wiki/patterns/guessed-domain-semantics.md): Instruction uses ambiguous terms; agent guesses grounding (6239 iter5: dropped the Goal dimension; 46646 iter6/7: side year-list 2018 instead of label-adjacent 2016; 6239 iter7: bucket conventions excluded 6 employees). FIX: dump the full grid with coordinates, then DELIBERATELY select label-adjacent main-area values over side lists and assert the instruction's worked examples before finishing — dumping alone is not enough.
- [answer-range-overstates-answer-extent](wiki/patterns/answer-range-overstates-answer-extent.md): answer_position can be larger than the real answer (57113 iter5: expected 3 of 4; 1818 iter7/iter8 t2: padded past the answer end — expected 32 values in a 132-cell range; writing None/""/IFERROR over non-answer cells counts as written-past-the-end). FIX: 'leave blank' means do NOT write the cell at all; write only cells with real values and never pad with "", 0, None, or IFERROR.
- [sparse-key-column-needs-forward-fill](wiki/patterns/sparse-key-column-needs-forward-fill.md): Lookup keys written only on the first row of a group (blank continuation rows) make SUMIFS/COUNTIF miss those rows ('number LOWER than expected', 46121 iter5/iter7/iter8: 2/48 wrong three times). FIX: forward-fill the key column (ffill) before grouping and assert the user's stated example (April payment in April, not March); note iter8 also crashed passing an unquoted range '2022'!B5:M8 — always quote sheet ranges as Python strings.
- [half-day-attendance-needs-day-level-dedup](wiki/patterns/half-day-attendance-needs-day-level-dedup.md): Attendance sheets with two half-day rows per person; counting raw code cells per category over both rows gives 'number HIGHER than expected' (11842 iter6: 2/96 wrong). FIX: merge first/second half marks into day-level values or sum the per-row summary columns; iter8 t2 still failed 2/96 LOWER from hand-typed category-name-to-column maps — match on the sheet's own header strings and treat an all-zero read-back as a broken lookup, not success.
