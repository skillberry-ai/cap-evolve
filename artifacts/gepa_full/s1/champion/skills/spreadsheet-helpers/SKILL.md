# spreadsheet-helpers

Helper scripts for spreadsheet manipulation. A script belongs here when a procedure recurs across
tasks (parse, locate, normalise, compute, validate). Each script is general, offline and
deterministic, takes its inputs as arguments, and writes only to the path it is given.

## scripts/helpers_1.py

Import with: `from skills.spreadsheet_helpers import helpers_1`

Call these helpers instead of re-implementing the procedure inline — they are the
recommended way to read, write and verify cells, and they avoid the most common
failure modes (wrong sheet name, wrong row offset, string values where typed
values are expected, writing outside the target range).

- `helpers_1.to_number(value)`: Convert a cell value or string to a float; return None if not
  numeric. Call it before doing arithmetic on values read from cells.
- `helpers_1.to_date(value)`: Convert a cell value or string to a datetime.date; return None on
  failure. Call it when comparing or ordering dates read from cells.
- `helpers_1.to_time(value)`: Convert a cell value or string to a datetime.time; return None on
  failure. Call it when a task asks for the time part of a date-time cell — write the resulting
  `datetime.time` object into the cell, NOT a formatted string like "06:08:00 PM"; graders check
  for the typed value.
- `helpers_1.find_sheet(workbook, wanted)`: Return the worksheet whose name matches `wanted`
  ignoring spaces/case. Call it instead of `wb.active` or assuming a sheet name; sheet names often
  carry trailing spaces.
- `helpers_1.read_range(path, sheet, ref, data_only=True)`: Read a rectangular range as evaluated
  values; returns a list of row lists. Call it to inspect the cells around the target range and to
  read lookup tables before computing. Example:
  `rows = helpers_1.read_range(path, "Sheet1", "A1:K13")`.
- `helpers_1.write_values(path_in, path_out, sheet, ref, values)`: Write a 2-D list of literal
  values into an exact target range and save. Call it to fill answer_position — it writes exactly
  the given range, no more, so you cannot accidentally touch cells outside the target. Pass real
  typed values (numbers, dates, times, booleans) computed in Python, not strings and not live
  formulas. Example:
  `helpers_1.write_values(in_path, out_path, "Sheet1", "K6:K10", [[26], [27], [28], [29], [30]])`.
- `helpers_1.verify_saved(path_out, sheet, ref)`: Re-open a saved workbook and return the values
  now in the target range. Call it after every write and print the result, together with a few
  neighbouring cells, before declaring the task done.
- `helpers_1.is_na_error(value)`: Return True when a cell holds the #N/A error (as an error object
  or text). Call it when scanning a broken formula column for cells you must fix.
- `helpers_1.used_extent(ws)`: Return (min_row, min_col, max_row, max_col) of real data in a
  worksheet. Call it instead of hard-coding row counts from the preview — the preview only shows
  the first few rows and the real extent is often larger.

## Suggested workflow with these helpers

1. Inspect: `find_sheet` for the sheet, then `read_range` over the used extent around the target.
2. Compute the answer in Python using `to_number` / `to_date` / `to_time` on the values you read.
3. Write literal typed values into the exact answer range with `write_values`.
4. Verify with `verify_saved` and print neighbouring cells; fix and re-write if anything is off.
